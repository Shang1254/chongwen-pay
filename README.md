# 崇文兰亭便民缴费通（武汉鼎诚物业）

面向老旧小区（无智能水电表）的微信缴费小程序 + Node.js 轻量后端 + 物业网页后台。
**2号楼试点 → 全小区 1200 户覆盖**。

- 中老年友好：**简约蓝白物业风**、大字体、高对比度、无广告入口、**缴费全程不超过 3 步**
- 三费合一：电费 / 水费 / 物业费，一键合并支付
- 业主认证：**手机号 + 房号**（与物业登记手机号核对），业主/租户身份区分，**支持多房产**切换
- 居民端：微信登录 → 绑定房号 → 微信支付 → **电子缴费凭证（带防伪码）** + 物业报修 + 订阅消息提醒（用户授权）
- 物业端：Excel/CSV 批量导入欠费账单、收款记录（可退款）、**对账文件导出**、**线下兜底收费登记**、一键催缴、报修处理、用量分析、监管留痕、**操作日志**
- 合规底座：支付直连物业企业商户号（无资金池、无二清）、**回调/退款/对账三件套**、个人信息加密存储、留痕哈希链防篡改、账单口径以物业系统为准（source 可追溯）
- 开箱即跑：演示模式下全链路可通，导入微信开发者工具就能看到首页

## 快速开始（详细步骤看《部署指南.md》）

```bash
# 1. 初始化数据库（或用 Workbench 执行 init.sql；可重复执行，不删数据）
mysql -u root -p < server/db/init.sql

# 2. 老库升级（已有数据必执行；新库也建议执行一次，幂等）
cd server && node db/migrate-v2.js

# 3. 启动后端（Windows 双击 server/scripts/start.bat）
npm install && node app.js

# 4. 浏览器验证
#    健康检查 http://127.0.0.1:3000/api/health
#    物业后台 http://127.0.0.1:3000/admin （admin / admin123）

# 5. 微信开发者工具 → 导入项目根目录 → 详情→本地设置→勾选"不校验合法域名"

# 6. （可选）灌入整栋楼演示数据
node scripts/seed-demo.js && node scripts/seed-property.js
```

## 三个 AI Agent 说明

| Agent | 触发时机 | 干什么 |
|---|---|---|
| ① 智能账单校验 | 绑定户号时、每次下单前 | 拦输错房号/姓名、防重复缴、金额比平时高 3 倍弹提醒；记录进 check_logs |
| ② 欠费自动提醒 | 每天上午 8 点后自动一轮 + 后台一键催缴 | 到期前 3 天提醒、逾期 1 天再催、每日欠费名单汇总、物业手动全员催缴 |
| ③ 用量分析统计 | 每月 1 号自动 + 后台手动 | 按楼栋/月份汇总水电用量（物业费自动排除），识别异常高耗户，后台可视化 |

## 合规设计（重点）

1. **无二清、无资金池**：微信支付商户号必须是武汉鼎诚物业企业主体，资金直达物业对公账户；
   本系统只记录订单与凭证，不做代收代付/资金归集，不设平台账户。
2. **个人信息加密**：报修联系电话、监管留痕中的业主姓名使用 AES-256-GCM 本地加密存储；
   凭证与留痕使用 HMAC 防伪；留痕表采用哈希链（后一条含前一条哈希），可校验是否被改动。
3. **监管留痕**：`audit_logs` 按武汉物业监管常见字段预置（记录号/小区/企业/房号/业主/费用类型/账期/金额/渠道/支付单号/时间/哈希），
   后台可导出 CSV 直接报送；正式对接住建监管系统时，只需按对方接口调整导出字段映射。
   ⚠️ 武汉住建部门接口未公开，具体字段以主管部门正式规范为准。
4. **零加价公示**：小程序首页、缴费页、凭证页均明示"水电费按武汉水务、国网湖北电力官方定价代收，物业不加收手续费"。
5. **试点防误触**：2号楼测试入口需邀请码（`config.testInviteCode`，默认 `CWLT-2-2026`，物业可随时修改），未解锁用户不能绑定户号。
6. **类目与资质**：微信类目选「生活服务 > 物业服务」，需武汉鼎诚物业营业执照、法人身份证、物业服务合同等材料，详见《上架审核指引.md》。

> ⚠️ 关于微信"生活缴费"官方接口：仅对水电事业单位/持牌服务商开放，普通物业无法直接接入。
> 本项目采用"微信支付收款进物业商户号 + 自建缴费台账自动销账"（物业总表转供模式），
> 并在 `agents/bill-check-agent.js` 预留 `queryGovAccount()`，未来拿到授权换一个函数即可。

> 📌 企业名称提示：项目里原配置为"武汉鼎盛佳物业管理有限公司"，本次按最新说明改为"武汉鼎诚物业服务有限公司"。
> 若营业执照名称不同，只改 `server/config.js` 的 `company` 一处即可（凭证、留痕、后台、审核材料都会跟着变）。
